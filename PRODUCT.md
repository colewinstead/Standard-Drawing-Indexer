# Standard Drawing Indexer

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
delegated: plain HTML/CSS/JavaScript; bundled PDF.js and pdf-lib; build tooling produces a single offline HTML file.

## Users
Roadway design teams assembling standard-drawing packages for individual jobs.

## Product Purpose
Find and preview MDOT standard drawings, select sheets or related multipart sets, arrange them, and export the original drawing pages as a combined PDF.

## Operating Context
Open the self-contained HTML directly from disk in desktop Chrome or Edge. No installation, server, or network is required. System file dialogs open and save projects and exports.

## Capabilities and Constraints
Bundle the supplied 217-sheet MDOT roadway library. Save small versioned project files containing project name, library identity, ordered selections, and sheet fingerprints. Review changed and missing selections when migrating projects between libraries. Explicit saving with unsaved-change warnings; no crash-recovery storage. Updates, arbitrary PDF imports, annotations, and favorites are deferred.

## Brand Commitments
Familiar engineering utility with a compact light workspace, restrained color, and resizable catalog, preview, and package panels. Bluebeam Revu and Windows File Explorer are familiarity references, without copied branding.

## Evidence on Hand
fixtures/Roadway Design Standard Drawings.pdf: MDOT Roadway Design standard drawings, 220 PDF pages including cover and two index pages. This is a supplied snapshot, not a claim of current agency approval.

## Product Principles
- Preserve original drawing appearance and page geometry.
- Make selection and final export order explicit.
- Never silently substitute revised drawings or omit missing selections.
- Keep the program and its initial library portable in one file.

## Accessibility & Inclusion
Keyboard-accessible selection, reordering, resizable panels, visible focus, labeled controls, and readable contrast.
