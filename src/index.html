    Library & help

    This program bundles the supplied MDOT Roadway Design Standard Drawings PDF: 217 drawing sheets, excluding its cover and two index pages.

    The source is a fixed snapshot, with mixed drawing issue and revision dates. It does not check for updates or establish that a drawing is appropriate for your project. Confirm the applicable agency requirements before use.

    Projects: Save and reopen .sdi-project.json files using Chrome or Edge. Projects contain selections and order, not PDF data. Keep the matching HTML program with your project records.

    Controls: Search working number, sheet number, or title. Select a row to preview; use its checkbox to include it. Related multipart sets have a “Select complete set” control. Use the arrow buttons or drag package rows to change export order.

    Keyboard: Ctrl/Cmd+S saves; Ctrl/Cmd+Shift+S saves as; Ctrl/Cmd+O opens a project. Arrow keys resize focused panel separators. Preview is visual; the catalog provides sheet identifiers and titles.
